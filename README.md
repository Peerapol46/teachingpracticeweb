# เว็บรายงานการฝึกประสบการณ์วิชาชีพครู

เว็บรายงานการฝึกสอนแบบหน้าเดียว (SPA) สำหรับ deploy ขึ้น **Firebase Hosting** (`*.web.app`)
โดยเก็บข้อมูลและไฟล์ทั้งหมดไว้ใน **Google Drive** ของเจ้าของรายงาน

โปรเจกต์ปลายทาง: https://teaching-practice-f47fa.web.app/

## การเข้าใช้งาน

เปิดเว็บครั้งแรกจะมีหน้าให้เลือกก่อนว่าจะเข้าแบบไหน

| ตัวเลือก | ผล |
|---|---|
| **ล็อกอินด้วย Google** | เก็บข้อมูลและไฟล์ไว้ใน Google Drive ของตัวเอง เปิดแก้ไขได้จากทุกเครื่อง และสร้างลิงก์แชร์ได้ |
| **ใช้งานแบบ guest** | ไม่ต้องล็อกอิน ใช้ได้ครบทุกหน้า แต่ข้อมูลอยู่ในเบราว์เซอร์เครื่องนั้นเท่านั้น และยังแชร์ไม่ได้ |

เลือกแล้วระบบจะจำไว้ ครั้งต่อไปเข้าเว็บได้เลยไม่ต้องเลือกซ้ำ
เริ่มแบบ guest ไว้ก่อนแล้วค่อยกด "ล็อกอินด้วย Google" ที่แถบด้านซ้ายทีหลังก็ได้ — ข้อมูลที่ทำไว้จะถูกอัปโหลดขึ้น Drive ให้อัตโนมัติ
กด "ออกจากระบบ" จะกลับมาที่หน้าเลือกอีกครั้ง
ส่วนคนที่เปิดจากลิงก์แชร์จะไม่เจอหน้านี้ — เข้าไปดูรายงานได้ทันที

## การเก็บข้อมูล

| สถานะ | ข้อมูลถูกเก็บที่ |
|---|---|
| **แบบ guest** | เบราว์เซอร์เครื่องนี้ (localStorage) — ใช้งานได้ครบทุกหน้า แต่แชร์ไม่ได้ และไฟล์ต้องไม่เกิน 2.5 MB |
| **ล็อกอิน Google แล้ว** | โฟลเดอร์ `รายงานการฝึกสอน (Teaching Practice)` ใน Google Drive ของผู้ใช้<br>· ข้อมูลทุกหน้ารวมอยู่ในไฟล์ `teaching-practice-data.json`<br>· รูป/สไลด์/ไฟล์แผน/ไฟล์วิจัย ถูกอัปโหลดเป็นไฟล์แยกในโฟลเดอร์เดียวกัน |

เว็บใช้ scope `drive.file` เท่านั้น → เข้าถึงได้ **เฉพาะไฟล์ที่เว็บนี้สร้างเอง** ไม่เห็นไฟล์อื่นใน Drive
เมื่อล็อกอินแล้วข้อมูลจะถูกบันทึกอัตโนมัติ (auto-save) และกดปุ่ม "บันทึก" เพื่อบันทึกทันทีได้

> ไฟล์ที่อัปโหลดจะถูกตั้งเป็น "ผู้ที่มีลิงก์เปิดดูได้" เพื่อให้รูปแสดงผลและให้ผู้รับลิงก์แชร์เปิดดูได้

## ติดตั้งครั้งแรก

### 1. สร้าง OAuth Client ID (สำหรับล็อกอิน + เก็บลง Drive)

1. เปิด [Google Cloud Console](https://console.cloud.google.com/) แล้วเลือกโปรเจกต์เดียวกับ Firebase (`teaching-practice-f47fa`)
2. **APIs & Services → Library** → เปิดใช้งาน **Google Drive API**
3. **APIs & Services → OAuth consent screen** → เลือก External → กรอกชื่อแอป/อีเมล → เพิ่ม scope `.../auth/drive.file`
   (ถ้ายังไม่ publish ให้เพิ่มอีเมลตัวเองใน **Test users**)
4. **APIs & Services → Credentials → Create credentials → OAuth client ID → Web application**
   - **Authorized JavaScript origins**:
     - `https://teaching-practice-f47fa.web.app`
     - `https://teaching-practice-f47fa.firebaseapp.com`
     - `http://localhost:5000` (สำหรับทดสอบในเครื่อง)
5. คัดลอกค่า **Client ID** (ลงท้ายด้วย `.apps.googleusercontent.com`)

### 2. สร้าง API key (สำหรับให้คนที่ไม่ได้ล็อกอินเปิดลิงก์แชร์ได้)

1. **Credentials → Create credentials → API key**
2. กด **Restrict key** → *Application restrictions* เลือก **Websites** แล้วใส่โดเมนข้างบน
   → *API restrictions* เลือกเฉพาะ **Google Drive API**

### 3. ใส่ค่าลงในเว็บ

แก้ไฟล์ `public/js/config.js`

```js
window.APP_CONFIG = {
  googleClientId: 'xxxxxxxx.apps.googleusercontent.com',
  googleApiKey: 'AIzaSy...',
  ...
};
```

ทำครั้งเดียวตอนติดตั้ง หลังจากนั้นผู้ใช้เห็นแค่ปุ่ม **"ล็อกอินด้วย Google"** ไม่ต้องกรอกค่าอะไรอีก

ถ้าไม่สะดวกแก้ไฟล์ กรอกผ่านหน้า **ตั้งค่า → ตั้งค่าขั้นสูง** ในเว็บก็ได้
(ค่าจะถูกเก็บไว้ในเบราว์เซอร์เครื่องนั้นเครื่องเดียว จึงแนะนำให้ใส่ในไฟล์ `config.js` มากกว่า เพราะใช้ได้กับทุกคนที่เปิดเว็บ)

> API key และ Client ID ของ Web app เป็นค่าที่เปิดเผยได้ตามปกติ ความปลอดภัยมาจากการจำกัดโดเมนและ scope

## Deploy ขึ้น Firebase Hosting

```bash
npm install -g firebase-tools     # ครั้งแรกครั้งเดียว
firebase login
firebase deploy --only hosting
```

โปรเจกต์ถูกตั้งค่าไว้แล้วใน `.firebaserc` (`teaching-practice-f47fa`)
หลัง deploy เว็บจะอยู่ที่ `https://teaching-practice-f47fa.web.app`

ทดสอบในเครื่องก่อน deploy:

```bash
firebase emulators:start --only hosting   # หรือ  npx serve public
```

```

  index.html           หน้าเว็บหลัก + ธีม (Tailwind CDN + Vue 3 CDN)

  js/drive.js          ล็อกอิน Google + อ่าน/เขียนไฟล์บน Google Drive
  js/store.js          ข้อมูลทั้งหมด + auto-save + โหมดแชร์
  js/ui.js             คอมโพเนนต์กลาง (การ์ด, ฟอร์ม, อัปโหลดไฟล์, โมดัล)
  js/pages.js          หน้าทั้ง 10 หน้า
  js/app.js            เมนู, หัวเรื่อง, ปุ่มล็อกอิน/แชร์, การสลับหน้า
```

ไม่มีขั้นตอน build — แก้ไฟล์แล้ว deploy ได้ทันที

## คำถามที่พบบ่อย

**เปิดเว็บแล้วขึ้นว่า "โหลดไฟล์ของเว็บไม่ครบ" หรือ console ฟ้อง `Cannot use import statement outside a module` / `Store is not defined`**
เบราว์เซอร์กำลังใช้ไฟล์ `js/*.js` เวอร์ชันเก่าที่ค้างอยู่ในแคช (ชื่อไฟล์ซ้ำกับของ deploy ก่อนหน้า) หรืออัปโหลดไฟล์ไม่ครบ

1. กด **Ctrl+Shift+R** (Mac: **Cmd+Shift+R**) เพื่อรีเฟรชแบบล้างแคช
2. ตรวจว่าไฟล์ใน `public/js/` ครบทั้ง 6 ไฟล์ และทับของเดิมหมดแล้ว (ถ้ามีไฟล์เก่าที่ไม่ใช้แล้วให้ลบทิ้ง) แล้ว `firebase deploy --only hosting` ใหม่
3. ถ้าแก้ไฟล์ js แล้วหน้าเว็บยังไม่อัปเดต ให้เปลี่ยนเลข `?v=1.0.1` ท้าย `<script src="...">` ใน `public/index.html` ทุกบรรทัดพร้อมกัน (เช่นเป็น `?v=1.0.2`)

**คำเตือน `cdn.tailwindcss.com should not be used in production` ใน console**
เป็นคำเตือนปกติของ Tailwind CDN ไม่ใช่ error และไม่กระทบการใช้งาน
ส่วนข้อความที่ขึ้นต้นด้วย `contentscript.js` / `ObjectMultiplex` มาจากส่วนขยาย (extension) ในเบราว์เซอร์ ไม่เกี่ยวกับเว็บนี้

**ล็อกอินแล้วขึ้นว่า "ยังไม่ได้ตั้งค่า Google Client ID"**
ยังไม่ได้ใส่ค่าในหน้า *ตั้งค่า* หรือใน `js/config.js`

**กดล็อกอินแล้วขึ้น error 400: redirect_uri_mismatch / origin ไม่ถูกต้อง**
โดเมนที่เปิดอยู่ยังไม่ได้อยู่ใน *Authorized JavaScript origins* ของ OAuth client

**เปิดลิงก์แชร์แล้วขึ้นว่าเปิดไม่สำเร็จ**
ยังไม่ได้ใส่ API key หรือ API key ถูกจำกัดโดเมนไว้ไม่ตรงกับโดเมนที่เปิด

**ข้อมูลหายเมื่อเปลี่ยนเครื่อง**
ถ้าไม่ได้ล็อกอิน ข้อมูลจะอยู่ในเบราว์เซอร์เครื่องเดิมเท่านั้น — ล็อกอิน Google เพื่อให้ข้อมูลตามไปทุกเครื่อง
หรือใช้ *ตั้งค่า → ดาวน์โหลดไฟล์ข้อมูล* เพื่อสำรองเป็นไฟล์ JSON
